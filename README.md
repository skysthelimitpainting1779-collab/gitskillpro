# GitSkillPro

Universal Git, GitHub, CI, multi-agent repository, and deployment operations for coding agents.

GitSkillPro is designed as a portable agent Skill plus executable tooling. The target architecture exposes the same safety and decision model through a Skill, CLI, MCP server, and capability-aware adapters for local Git, GitHub, deployment providers, and host-native plugins/connectors.

Status: architecture/design phase.
